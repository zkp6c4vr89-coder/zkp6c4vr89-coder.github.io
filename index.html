This started as a "how does that even work?" moment, looking at artwork made purely out of keyboard characters. One question led to another, and somehow I ended up building a whole studio for it.

ASCII Studio takes any picture, video or live camera and redraws it using only characters — dense ones like @ # % where it's bright, light ones like . : , where it's dark, and little strokes / | \ - that trace the edges. In full colour, with a soft glow.

It lives in three places: a website anyone can use, a browser extension, and a desktop app. Everything happens on your device. No accounts, no uploads, no tracking. Just letters.

— Nandhu (probably still tweaking the glow)

01 how does it work?

six tiny steps, done thirty times a second on your graphics card:

  1. ▓▓▒▒░░
▓▒▒░░·
    shrinksquash the picture so each pixel becomes one character cell
  2.   ☼
 0.82
    measurehow bright is each cell? add contrast to taste
  3.  .:-=
 +*#@
    pickchoose a character with exactly that much "ink"
  4.  /‾‾\
 |  |
    tracewhere brightness jumps, follow the edge with / | \ -
  5.  ◐ ◑
 ◒ ◓
    colourtint every character with the picture's own colour
  6.  ✧ ✦
 ✦ ✧
    glowstamp them all at once, then add a soft bloom

→ the same recipe powers the website, the extension and the app!

04 the desktop app

┌─[ ASCII Studio.app ][_][□][x]

The whole studio as a real app — plus live ASCII wallpapers that live behind your desktop icons.

  • water, butterflies, fireflies, rain or stars — or your own photo, moving
  • they follow your mouse, slow down on battery & nap when you lock the screen
  • a friendly setup guide the first time you open it
  • lives in your menu bar · can start quietly when you log in
  • set any ASCII picture as your still wallpaper, too

first time opening it? (it isn't signed with a pricey certificate, so…)
  • macOS: drag it into Applications, then right-click it › Open › Open. If macOS says it's "damaged", run xattr -cr "/Applications/ASCII Studio.app" in Terminal once.
  • Windows: if a blue SmartScreen box appears, click More info › Run anyway.
  • Linux: chmod +x ASCII-Studio-*.AppImage and run it, or sudo apt install ./ASCII-Studio-*.deb.
